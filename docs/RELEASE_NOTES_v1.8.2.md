# v1.8.2

## Games page lists games only

**All games** and search no longer show categories that aren't games, such as Just Chatting, IRL, Music, Art, ASMR, Sports, Talk Shows & Podcasts, Chess, Poker and Slots. These are the categories Twitch itself tags as IRL. **Special Events** stays because it runs drop campaigns, and any category with drops on your account still appears under **With drops**.
