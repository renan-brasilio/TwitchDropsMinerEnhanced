# v1.3.1

## Settings

- When a Twitch account is connected, **Settings → Twitch account** shows only **Disconnect**. **Connect with Twitch** and the advanced browser-token form are hidden until the account is disconnected.
- After disconnecting, the sign-in options return and **Disconnect** is hidden.

## Verification

- The running dashboard with a connected account showed only **Disconnect**, with no Connect button or token form.
- The release workflow runs the regression suite before packaging.
