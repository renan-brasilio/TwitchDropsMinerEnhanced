Advanced: authenticate with a browser token
Direct browser token authentication:
  1. Sign in to twitch.tv in your browser.
  2. Open Developer Tools (Cmd+Option+I on Mac, or F12).
  3. Select Application (Chrome/Edge) or Storage (Safari/Firefox) → Cookies → https://www.twitch.tv.
  4. Copy the auth-token cookie value. Treat it like a password; never share it.
